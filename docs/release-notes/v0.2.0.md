# ChatGPT Account Keeper 0.2.0

首个 Rust + Tauri 桌面客户端版本，面向 Windows x64、macOS Apple Silicon/Intel 和
Linux x64。

## 主要变化

- 全新的 Tauri 管理端，覆盖账号、任务、代理、会话、Profile、历史和设置。
- 管理端通过本地 Named Pipe/Unix Socket 连接私有 Agent，不监听管理端口、不加载远端页面。
- 内置 Tauri updater；Windows、两种 macOS 架构和 Linux AppImage 均带 updater `.sig`。
- 延续既有数据目录、账号、Chrome Profile、SQLite、代理、历史与调度数据。
- 发布包包含固定版本的私有 Node/mihomo、四平台 Agent SBOM、源码归档和 SHA-256 清单。

## 从 Avalonia 0.1.x 迁移

本版本不提供 Avalonia → Tauri 应用内升级桥接。请先退出旧版 Avalonia 客户端，再手动安装
对应平台的 `v0.2.0`；不要先删除数据目录或 Chrome Profile。

后续 Tauri 版本将通过 Tauri updater 更新。
