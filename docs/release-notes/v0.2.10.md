# ChatGPT Account Keeper 0.2.10

## Agent 连接与启动鲁棒性优化

- **优化 Windows 命名管道可用性探测**：改用系统调用检查管道状态，避免元数据探测意外消耗唯一的管道实例而产生空连接或连接超时。
- **并发启动互斥保护**：防止应用初始化与后台任务同时拉起 Agent 时的竞态；慢启动期间若 Agent 正在初始化，不会被误判并强制回收。
- **启动自动梯度重试与离线手动重连**：首次连接超时后自动按梯度退避重试；连接断开时，侧栏状态与操作按钮切换为“重新连接 Agent”，支持一键恢复。
- **连接排查说明与依赖一致性**：文档补充了代理软件 TUN 模式与私有代理内核出口的排查建议；同步规范了前端依赖树锁定文件。
