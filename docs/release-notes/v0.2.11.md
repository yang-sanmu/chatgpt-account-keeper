# ChatGPT Account Keeper 0.2.11

## 自定义代理与设置保存优化

- **合并自定义代理导入与新增**：“新增代理”弹窗支持直接粘贴 `IP:PORT:USER:PWD`、`hostname:port@username:password`、代理 URL 或 curl 命令并点击“自动识别”，自动提取服务器、端口与账密，支持人工核对与修改。
- **支持多行批量自动识别**：弹窗支持批量粘贴多条代理字符串，一键完成多条解析并批量保存。
- **Agent 配置保存过滤只读字段**：修复前端在更新 Agent 设置时携带 `schedulerEnabled` 等只读字段导致契约校验警告的问题，保存前严格过滤可写字段。
