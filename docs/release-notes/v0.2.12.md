# ChatGPT Account Keeper 0.2.12

- 账号详情新增浏览器环境设置：语言、时区可以继承分组，也可以固定到账号；固定后换组仍保留。
- 环境修改在下次打开浏览器时生效，已打开窗口保持原配置，页面显示待生效状态。
- 修复 Windows 后台浏览器的地区时区应用，保留普通模式的代理和付款直连行为。
- 数据库升级前自动创建一致性备份。客户端与 Agent 需要配套更新；回退旧版须停机恢复升级前备份，保留升级后的数据副本。
- 本版仍使用普通网络模式，未开放 WFP 严格网络保护或独立 TUN，不宣称完全替代指纹浏览器。
- Windows Authenticode 代码签名改为可选，正式更新包继续使用原 Tauri updater 签名。
