# ChatGPT Account Keeper 0.2.2

## 优惠资格

- 刷新账号状态时同步检查 Plus 优惠资格，区分“免费试用”与“半价优惠”，无需单独调度。
- 使用后端 JSON 接口判断，不依赖页面语言或文案，适用于不同出口节点。
- 账号状态显示可用优惠，账号页新增优惠资格筛选。
- 检查暂时失败时保留同一邮箱上次确认的结果，并标记待复核。

## 修复

- 修复在同一浏览器资料中切换登录邮箱后，旧邮箱优惠资格被错误沿用的问题。
- 优惠资格持久化保存，重启后仍可查看。
