# ChatGPT Account Keeper 0.2.4

## 分组地区设置

- 新建代理分组后立即按节点出口探测时区和语言，无需重启应用才能看到结果。
- 修复印度节点自动语言可能错误显示为 `en-US` 的问题，现按 `Asia/Kolkata` 使用 `en-IN`。

## Profile 与账号管理

- Profile 操作改为增量更新列表，归档、还原、清理和账号删除后不再反复全量扫描。
- 删除账号时默认停用账号并保留 Profile；永久删除会同时彻底删除账号与 Profile。
- 保留孤儿 Profile 作为迁移、磁盘异常或历史数据的恢复入口，正常账号流程不会产生孤儿。

## 自动调度

- 新增“自动调度时获取优惠资格”开关，默认开启。
- 关闭自动巡检后，自动调度仍可复用本次 Chrome 会话更新优惠资格，不会额外启动浏览器。
- 优惠查询失败只标记为待复核，不影响本轮自动对话。
