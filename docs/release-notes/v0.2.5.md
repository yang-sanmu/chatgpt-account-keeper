# ChatGPT Account Keeper 0.2.5

## 自定义代理节点

- 支持导入自有 HTTP、HTTPS 和 SOCKS5 代理，兼容 `hostname:port@username:password`、代理 URL 与 curl 代理参数。
- 订阅节点和自定义节点分开管理；订阅列表默认折叠。
- 自定义节点支持新增、编辑、命名、启停、测速和删除，可修改服务器、端口、协议及认证信息。
- 编辑节点保留分组绑定；刷新订阅保留自定义节点和名称。
