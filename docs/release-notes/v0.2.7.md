# ChatGPT Account Keeper 0.2.7

## 优惠资格检查扩展与新建账号窗口保留

- 优惠资格支持 2/3 个月半价：在原有 1 个月半价与免费试用基础上，扩展支持 2 个月和 3 个月半价优惠券校验（`plus-2-months-50-pct-off`、`plus-3-months-50-pct-off`），并在页面检查中兼容 `offline` 状态保留待复核标记。
- 新建账号支持保留登录窗口：新建账号后默认保留浏览器窗口供用户继续操作，同时在登录成功后自动复用页面检查一次优惠资格；创建时支持勾选“登录成功后自动关闭浏览器”。
