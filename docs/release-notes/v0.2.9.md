# ChatGPT Account Keeper 0.2.9

## 网页登录同步与账号识别优化

- **打开网页自动同步会话与邮箱**：在“打开网页”窗口完成登录后，系统会自动采样并验证会话状态，同步回填已认证的邮箱与昵称至账号资料并实时更新界面，无需手动重新录入。
- **未识别邮箱独立标识与筛选**：尚未识别邮箱的账号统一显示为“邮箱未识别”（不再混同于“未登录”），工具栏新增“邮箱未识别”专属筛选，便于快速定位与补充信息。
- **强制重登二次确认防护**：普通“登录”操作默认保留现有会话与登录态；“强制重登”新增二次确认对话框，防止误触清除已保存的凭据。
